## What Is It
A lightweight Twitter/X-inspired social feed built as part of Scrimba's Frontend Career Path. Users can create posts, like tweets, retweet content, and interact with a dynamic timeline powered by JavaScript.

### Features
- Create and display tweets
- Like and unlike posts
- Retweet functionality
- Dynamic feed rendering
- Interactive UI updates without page reloads

### Built With
- HTML
- CSS
- JavaScript


### What I Practiced
This project focused heavily on JavaScript fundamentals, including object manipulation, event handling, conditional rendering, array methods, and building interactive user interfaces from structured data.
